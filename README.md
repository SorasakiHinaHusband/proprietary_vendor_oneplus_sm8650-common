# OnePlus SM8650 common proprietary vendor blobs

Common proprietary files for OnePlus devices based on Qualcomm SM8650
(pineapple), extracted from OxygenOS `11.F.58` (Android 16).

## Maintainer

- **SorasakiHinaHusband** — <https://github.com/SorasakiHinaHusband>

## Branch

- `Cinderella` — MikuUI (Android 17 / BP2A)

## Usage

This repository is consumed as `vendor/oneplus/sm8650-common`; `Android.bp` is
generated by `extract-files.py` from the common device tree and declares every
blob as a prebuilt module.
